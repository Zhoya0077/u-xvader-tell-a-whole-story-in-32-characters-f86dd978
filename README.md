A Wi-Fi network name that tells a whole story in 28 characters: "Ex took dog. Kept the Wi-Fi." A breakup in two sentences — the ex got the dog, but the narrator kept the one thing that really mattered. No stock Wi-Fi joke, no slogan: a situation, a character, and something that happened, in one glance at a phone's network list.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it to stdout, after a self-checking gate verifies it is 1–32 characters and not only whitespace.
